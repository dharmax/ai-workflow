## Enforcement

Investigation, production and verification use the same effective Ticket
governance resolver over existing RuleStore and native graph ownership.
Mandatory applicability ambiguity blocks resolution. JavaScript and TypeScript
remain distinct. Rule identity includes operative content, scope, languages,
importance, status, revision, inline examples and checker instruction/version,
configured critic identity and acceptance prompt fingerprint. Governing
Decision fields and accepted Aspect criteria also bind the overall signature.
Unrelated advisory records do not invalidate mandatory proof.

The existing acceptance schema now requires identifiable assessments for every
mandatory Rule at closure: exact logical ID, revision, fingerprint, verdict,
nonempty explanation, concrete cited evidence and explicit limitations.
Missing, duplicate, unknown, stale, uncited, failed or inconclusive assessments
cannot authorize Done. Justified not_applicable remains explicit.
`critic=none` cannot bypass mandatory acceptance.

The resolver privately pins governance, checks it after preparation,
implementation and independent acceptance and before proof closure, and
routes Rule failures into its existing bounded repair loop. Proof reuse also
requires current governance, contract, source hashes, test execution and Rule
coverage. Source proposals cannot mutate Product/Ticket semantics or canonical
workflow state. Producer mutation of its dossier cannot erase pinned duties.

Current source context includes no-change authored scope, complete small
whole-file scope and complete authored acceptance tests; exact Symbol scope
remains narrow. Duplicate declaration outlines are omitted when complete
Symbol source is already supplied. Unrelated regression-test target references
are filtered from review metadata, retaining every executed test result.
The existing 64,000-character code and 80,000-character review caps remain.
File, supplied mandatory source Symbol and executed TestNode citations are
accepted; invented Symbols in real files are rejected.
