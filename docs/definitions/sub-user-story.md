# Sub-US

A **meaningfully different episode of use** expressed as a variant of an existing [US](user-story.md). An ordinary conditional outcome within the same episode can remain in the parent's Expected Result.

A sub-US:
- **inherits the parent's entire effective definition**, including common Epic material;
- may **refine or replace** the distinguishing portions; everything not changed stays inherited;
- is itself a US, with the same field meanings;
- uses the title **`Parent US title - distinction`** (e.g. `Save avatar - Existing avatar`).

The suffix states the distinction; it does not replace defining it. Do not create a sub-US for each parameter, internal step or historical bug assertion. Detailed field-by-field editing mechanics are not yet specified.
