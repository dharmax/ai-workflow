# Sub-US (sub-User/Actor Story)

**Status:** Developer-agreed criterion.

A variant modeled as a sub-US **when it represents a meaningfully different episode of use**. A conditional outcome within the same episode can instead remain in its parent's [Expected Result](expected-result.md).

A sub-US is still a US and uses the same [User/Actor Story definition](user-story.md). It is not a device for turning every branch, implementation step, parameter or bug assertion into a new Story.

Whether and how the sub-US inherits additional fields from its parent US remains **undecided**. Do not manufacture inheritance or duplication rules in the meantime.
