# Initial State

**Status:** Developer-agreed field.

The **relevant situation before the [Actor](actor.md) performs the [Action](action.md)**.

It can describe an existing, partial or otherwise **non-pristine** situation; never assume a clean installation, empty backlog or ideal starting condition unless specified. An [Epic](epic.md) may provide common Initial State, with US-specific situation added where necessary.

How overlapping or conflicting Epic/US text is composed is not yet formally settled. Do not invent an override rule.
