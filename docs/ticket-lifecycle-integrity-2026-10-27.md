## Demonstrated defects and corrections

1. **Release left execution running on the board.** `releaseTicket` previously removed only the claim. It now atomically clears the claim, returns owned In Progress work to Todo, and appends its transition/lease history. An explicit release with no claim is idempotent and does not retroactively clean old Tickets.
2. **Resolver outcomes and persistent lanes disagreed.** A failed/needs-input resolution could leave In Progress even though the operation had stopped. Resolver cleanup now records Blocked plus the concrete reason for the stopped owned Ticket; completed and cancelled work retain their lanes. Existing same-agent leases adopted by the resolver are released too.
3. **Cancellation defeated cleanup and reporting.** Release now mirrors the existing exact-admission cleanup policy: a live project-write owner can release its own lease despite cancellation; read-only/expired authority cannot gain write access. Resolver cleanup checks the expected agent so an expired predecessor cannot release a replacement owner's lease. The public wrapper skips its cancelled duplicate journal write; the owner already persists the stopped reason atomically.
4. **Non-executing lane changes retained live claims.** Existing direct persistence and Product-batch writers now clear claims when transitioning out of In Progress. Coherent completion clears the claim in the same conditional commit as the receipt/Done transition and journals that release.
5. **Active reservations were hidden.** `getActiveClaims` previously searched only In Progress; resolver reservations can legitimately precede that lane. Active-lease reporting now examines all Tickets independently of lane.
6. **Mtime-only Markdown could restore stale state and erase specification layout.** Export includes the existing Ticket revision. Import refuses to overwrite an existing Ticket from an older or unversioned card, and writes against the observed revision. Current-card editing remains supported. Stale replay cannot reopen Done/Cancelled or remove a newer owner's claim. Unchanged cards do not increment versions/journal history. Unchanged flattened summaries preserve the canonical multiline body. A fresh forged Done still fails through the existing independent-completion guard.
7. **MCP accepted nonpositive lease durations.** The public schema and claim owner now require finite positive durations, matching CLI validation.

No automatic expiry sweep, alternate state field, cleanup script, receipt store, retry system, schema migration, or sync/export performance change was added. Lease expiry permits explicit takeover; it is evidence of lost ownership, not proof that work is complete. Atomic competing claims already reject stale writes; an exploratory two-store race confirmed one winner and no overwritten lease.
